Title: 사람인 고객센터 — 이력서 사진 등록, 수정 방법
Fetched: 2026-10-21 (node fetch, page text; CONTENT1021 Step B1; check:quotes --exact)
Verbatim lines:
개인인정보 수정 페이지 또는 이력서 등록 및 수정페이지에서 등록할 수 있습니다. 사진 픽셀이 클 경우 자동으로 회전되어 등록됩니다.
● STEP1 : 연필 아이콘 클릭 → '사진 추가' 클릭 ● STEP2 : [파일 선택] 버튼 클릭 → 사진 등록 후 [등록] 버튼 클릭
※ 사진 파일 등록이 원활하지 않을 때(사진 파일 회전되어 등록되는 경우 등) 고객센터에서 대신 사진 파일을 등록해드리는 것에 동의한다면, 이메일 문의를 통해 고객센터로 사진 원본 파일을 첨부해서 등록 요청해주시기 바랍니다.
단, 등록된 이력서 사진 픽셀 그대로 저장되기에 픽셀을 조절하거나 할 수는 없는 점 참고해 주세요
● STEP1 : MY홈 페이지에서 우측 상단 '000' 클릭 → [개정정보 수정] 클릭 ● STEP2 : 카메라 아이콘 클릭 → [프로필 편집] 버튼 클릭
이력서에 등록한 사진 별도 다운로드를 원한다면, 이력서 사진에 마우스 우클릭 → 이미지를 다른 이름으로 저장 클릭해 주시면 됩니다.
