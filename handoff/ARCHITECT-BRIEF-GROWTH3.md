## Failure modes
| Path | Realistic failure | Handling | User sees |
|---|---|---|---|
| Source fetch | bot UA blocked / script shell | via:browser, else draft (not rendered) | nothing (no page) |
| Wrong fact | quote misread or paraphrase drift | check:quotes verbatim + number-needs-source build test | build fails |
| Thin/duplicate | agency swap across guides | DUP_LIMIT 0.45 in check-dist + decision 4; Richard reads each | build fails / review |
| Tool page drift | new title enters /id-photo/ 관련 안내 → glyphs + precache | pins + unit test + dist diff vs baseline | build/test fails |
| Precache | a precached page grows (headroom 1.3 KB) | check-dist precache gate on 4 variants | build fails |
| Meta length | title > 40 / desc outside 40–80 | schema + check-dist meta | build fails |
| Snippet edit hurts | CTR or position drops | per-guide revert, baseline table, re-check 12-15 | no error (tracked in report) |
| GSC page×query | API error / quota | note line, other sections intact (unit test) | report says 오류 |
| Hub misses new spec rows | hub filters by a fixed list | Bob checks in G2 acceptance; escalate (Hub.astro forbidden) | covered by an explicit check |
| Merge with REV2/3 | overlapping files | whitelist; Bob lists touched files in REVIEW-REQUEST | none |
| Source changes later | 기관 updates rules | existing source-watch weekly + 400-day T9 | build fails at 400 days |
