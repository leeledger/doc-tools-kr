## 영문주소 변환기는 이럴 때 씁니다

- 해외 쇼핑몰에서 물건을 살 때 배송지 칸(Address·City·State·ZIP)에 내 주소를 영문으로 나눠 적어야 할 때 씁니다.
- 해외 사이트 회원가입이나 해외 송금, 영문 서류에 집 주소를 영문으로 적어야 할 때 씁니다.
- 외국에 있는 친구에게 우리 집 주소를 영문으로 알려 줄 때 씁니다.

## 휴대폰과 PC에서 쓰는 순서

1. 「영문으로 바꿀 주소」 칸에 「세종대로 110」처럼 도로명과 건물 번호를 적거나, 「반포동 18-1」처럼 동 이름과 번지를 적고 「찾기」를 누릅니다.
2. 「찾은 주소 ○개」 아래 목록에서 내 주소를 찾습니다. 목록이 길면 「더 보기」를 누르고, 맞는 주소 옆의 「이 주소 쓰기」를 누릅니다.
3. 「상세주소 (동·호)」에 「101동 1203호」처럼 적으면 영문으로 바뀐 동·호가 바로 아래에 나옵니다.
4. 「해외 직구 주소 칸에 나눠 넣기」에서 칸마다 넣을 값을 하나씩 「복사」해 쇼핑몰의 같은 이름 칸에 붙여 넣습니다. 칸이 하나뿐인 곳에는 「한 줄로 복사」를 씁니다.
5. 나라 칸에는 화면에 나온 대로 South Korea (Republic of Korea)를 고릅니다.

## 상세주소는 이렇게 바뀝니다

「상세주소 (동·호)」 칸에 적은 동·층·호는 아래처럼 바뀝니다. 숫자와 영문, 쉼표는 적은 순서 그대로 남습니다.

- 「101동 1203호」 → 101-dong 1203-ho
- 「3층」 → 3F, 「지하1층」 → B1F
- 「지하 3호」 → B3-ho

오피스텔이나 상가처럼 층과 호를 함께 적는 주소는 「5층 502호」처럼 한 칸에 이어 적으면 됩니다. 동·층·호와 숫자 말고 다른 한글이 섞이면 영문 줄이 만들어지지 않으니, 건물 이름 같은 부분은 빼거나 영문으로 직접 적어 주세요.

## 목록에서 내 주소를 고를 때

같은 도로명이 여러 지역에 있으면 찾은 주소 목록에 비슷한 주소가 여러 개 나옵니다. 각 주소에 함께 나오는 우편번호와 한글 주소의 시·도, 구 이름을 보고 내 주소를 고르세요. 헷갈리면 「반포동 18-1」처럼 동 이름과 번지로 다시 찾으면 목록이 짧아집니다.

## 결과가 이상할 때

- 「찾은 주소가 너무 많아요」가 나오면 건물 번호까지 적어 다시 찾습니다. 도로명만 적으면 같은 길의 모든 건물이 나옵니다.
- 「찾은 주소가 없어요」가 나오면 도로명주소와 지번 주소 가운데 다른 쪽으로 적어 봅니다. 집 주소를 모르겠다면 우편물이나 관리비 고지서에 적힌 주소를 보세요.
- 「숫자만으로는 찾을 수 없어요」나 「시·도 이름만으로는 찾을 수 없어요」가 나오면 도로명이나 동 이름을 함께 적습니다.
- 상세주소 칸에 동·층·호 말고 다른 한글을 적으면 영문으로 바뀌지 않습니다. 건물 이름을 꼭 넣고 싶다면 영문으로 직접 적어 주세요.
- 「인터넷에 연결된 뒤에 다시 찾아 주세요」가 나오면 와이파이나 데이터가 켜져 있는지 확인합니다. 「잠깐 너무 많이 찾았어요」가 나오면 몇 초 기다렸다가 다시 누릅니다.
- 「이 주소는 칸으로 나누지 못했어요」가 나오면 한 줄 주소를 먼저 쓰고, 칸이 나뉜 곳에는 아래 값을 참고해 채웁니다.

## 주의할 점

- 쇼핑몰마다 칸 이름이 조금씩 다릅니다. 「Street」나 「Address 1」은 Address line 1과, 「Province」나 「Region」은 State·Province와 같은 칸으로 보면 됩니다.
- 받는 사람 이름은 여권과 같은 영문으로 적어 두면 해외 사이트의 다른 서류와 맞추기 쉽습니다. 여권 영문 이름이 아직 없다면 [영문 이름 변환기](/english-name/)에서 표기를 먼저 확인해 보세요.
