## 파일이 안 올라가는 세 가지 이유

유웨이 원서접수 안내에 따르면 서류 파일이 올라가지 않는 경우는 이 세 가지예요.

1. 파일 크기가 너무 큰 경우
2. 받는 확장자(파일 형식)가 아닌 경우
3. 파일 이름에 특수문자 등이 들어간 경우

파일 이름에 특수문자나 띄어쓰기가 있으면 올리기 어렵다고 하니, 이름은 한글이나 영문으로만 바꿔 두세요. 받는 형식과 크기는 지원하는 대학의 모집요강에서 확인하세요.

## 파일 이름 짓는 법

유웨이 안내처럼 이름에 특수문자나 띄어쓰기가 있으면 올리기 어려워요. 이름은 이렇게 지으면 무난해요.

- **한글이나 영문으로만**: 「홍길동성적증명서」처럼 한글이나 영문으로 붙여 써요. 괄호, 따옴표, 점, 띄어쓰기는 빼요.
- **확장자는 그대로**: 이름 끝의 「.pdf」, 「.jpg」 같은 확장자는 지우거나 바꾸지 마세요. 형식을 바꾸려면 아래 「받는 형식이 아닐 때」처럼 다시 저장해야 해요.
- **서류마다 다르게**: 같은 이름의 파일이 여럿이면 어떤 칸에 무엇을 올렸는지 헷갈려요. 서류 이름을 넣어 구분하고, 고친 파일에는 고친 것을 알 수 있게 이름 끝에 표시를 붙여요.
- **대학이 정한 규칙이 먼저**: 모집요강에 파일 이름 규칙이 있다면 그 규칙을 따르세요.

## 파일이 너무 클 때

- PDF 서류는 [PDF 용량 줄이기](/pdf-compress/)에서 줄일 수 있어요.
- 사진으로 찍은 서류는 [사진 용량 줄이기](/photo-compress/)에서 원하는 KB 이하로 줄일 수 있어요.
- 여러 장을 하나의 PDF로 내야 하면 [PDF 합치기](/pdf-merge/)로 묶을 수 있어요.

신분증 사본도 함께 내야 한다면 [신분증 사본 만들기](/id-copy/)에서 필요 없는 정보를 가리고 JPG나 PDF로 저장할 수 있어요. 만드는 순서는 [신분증 사본 만드는 법](/guide/id-card-copy/)에 정리했어요.

## 받는 형식이 아닐 때

파일을 오른쪽 클릭해 속성을 보면 파일 형식(확장자)을 확인할 수 있어요. 받는 형식과 다르다면 형식에 맞게 다시 저장해야 해요.

- **아이폰 사진(HEIC)이나 PNG를 JPG로**: [사진 JPG 변환](/image-to-jpg/)에서 바꿔요. 유웨이는 PC의 그림판에서 파일을 열고 「다른이름으로 저장」에서 원하는 확장자를 골라 저장하는 방법도 안내해요.
- **사진을 PDF로**: 서류를 찍은 사진을 PDF로 내야 한다면 [사진 PDF 변환](/jpg-to-pdf/)으로 만들어요.
- **한글(HWP) 문서를 PDF로**: 자기소개 자료처럼 한글로 쓴 문서를 PDF로 내야 한다면 [HWP PDF 변환](/hwp-to-pdf/)을 써요.
- **PDF를 사진으로**: 사진만 받는 칸이라면 [PDF JPG 변환](/pdf-to-jpg/)으로 필요한 쪽만 JPG로 바꿔요.

## A4 크기로 올려 달라고 할 때

스캔하거나 사진으로 찍은 PDF는 A4 용지를 찍었어도 대학이 원하는 크기와 다를 수 있어요. 유웨이는 이렇게 다시 저장하라고 안내해요.

1. 고칠 PDF 파일을 열어요.
2. 인쇄 버튼을 눌러요.
3. 프린터를 PDF로 골라요.
4. 용지를 A4로 정해요.
5. 인쇄를 눌러 PDF로 다시 저장해요.

유웨이는 이렇게 다시 저장한 PDF가 정확한 A4 크기라 올릴 때 편하다고 안내해요. 다시 저장한 파일은 원래 파일과 이름을 다르게 해 두어야 어느 것을 올릴지 헷갈리지 않아요.

## 원서는 윈도우 PC에서

유웨이 안내에 따르면 파일 제출과 원서접수는 윈도우 PC의 크롬·엣지에 맞춰져 있고, 맥과 휴대폰에서는 되지 않아요. 휴대폰으로 찍은 서류는 PC로 옮겨 제출하세요.

휴대폰으로 찍은 서류 사진은 나에게 메일로 보내거나 메신저의 PC 버전에서 받는 식으로 PC에 옮긴 뒤, PC에서 크기와 형식을 맞춰 올리면 돼요. 옮기는 동안 사진이 메신저에서 자동으로 줄어들 수 있으니, PC에서 열어 글자가 또렷한지 한 번 더 보세요.

## 서류는 어디에 물어볼까요

원서접수 사이트는 접수 화면을 운영할 뿐, 어떤 서류를 내야 하는지는 대학이 정해요. 진학어플라이도 제출서류 상담은 하지 않으니 대학 모집요강을 확인하거나 학교 입학처에 문의하라고 안내해요. 모집요강을 볼 때는 이런 것을 찾아 두세요.

- 전형마다 내야 하는 서류의 이름과 발급 기준(원본, 사본 등)
- 파일로 낸다면 받는 형식과 크기, 한 칸에 올리는 파일 수
- 우편으로 낸다면 서류를 보내야 하는 기간과 받는 주소
- 서류를 내지 않았을 때 어떻게 되는지

이 네 가지를 대학별로 미리 적어 두면 파일을 고칠 때마다 모집요강을 다시 뒤지지 않아도 돼요. 파일을 올리는 일은 마감 날로 미루지 말고 여유 있게 해 두세요. 그래야 안 올라가는 파일을 고치거나 서류를 다시 발급받을 시간이 생겨요.

## 자기소개서를 한글·워드에서 옮길 때

자기소개서를 원서접수 화면의 입력 칸에 써야 하는 학교라면, 한글이나 워드로 써 둔 글을 옮길 때 유웨이 안내에서 볼 점은 이래요.

- 붙여넣기는 되는 학교에서만 쓸 수 있어요. 붙여넣기가 되지 않는 학교도 있어서, 그런 곳은 직접 쳐서 넣어야 해요.
- 붙여넣으면 웹페이지 형식으로 바뀌어 글자수, 글자 크기, 글씨체가 달라질 수 있어요. 붙여넣은 뒤 내용을 다시 확인하고 저장하세요.
- 특수문자는 붙여넣으면 출력 프로그램에서 글자를 알아보지 못해요. 학교의 작성 유의사항에 나온 방법으로 넣으세요.
- 자기소개서에는 따로 제출 버튼이 없고, 아래의 [저장하기]로 저장해 두면 마감일에 자동으로 제출된다고 안내해요.

글자수 제한이 있다면 옮기기 전에 [글자수 세기](/char-count/)에 붙여 넣어 공백 포함·제외 글자수를 미리 맞춰 두면, 입력 칸에서 잘리는 일을 줄일 수 있어요.

## 우편이나 직접 내야 할 때

<figure class="guide-fig"><img src="/img/guide/univ-docs-upload/2-online-vs-mail.svg" width="720" height="252" alt="온라인 파일 제출은 원서접수 사이트에 형식과 크기와 이름을 맞춰 윈도우 PC에서 내고, 우편이나 직접 제출은 봉투 표지를 출력해 대봉투 앞면에 붙여 택배나 등기나 직접 내는 차이를 나란히 그린 그림" loading="lazy" decoding="async"><figcaption>파일로 받는 대학도 있고 종이로 받는 대학도 있어요. 두 가지를 섞어 받는 대학도 있으니 모집요강을 끝까지 읽어 보세요.</figcaption></figure>

서류를 파일이 아니라 종이로 받는 대학도 있어요. 유웨이 안내에 따르면 원서접수 뒤 제출서류를 준비하고 발송용 봉투 표지를 출력해 대봉투 앞면에 붙인 다음, 택배·등기우편·직접제출 가운데 모집요강이 정한 방법으로 내요. 서류가 필요한데도 봉투 표지를 출력하지 않는 경우가 있다고 하니 모집요강을 자세히 확인하세요. 유웨이는 제출서류를 내지 않으면 입학사정에서 불합격되거나 불이익을 받을 수 있다고 안내해요.

## 도착 확인이 바로 안 될 때

우편으로 보낸 서류의 도착 확인은 학교가 서류를 받은 뒤 직접 반영해요. 그래서 유웨이 안내처럼 서류가 도착했어도 처리가 늦어 바로 확인이 안 될 수 있어요. 등기나 택배로 보냈다면 받은 송장 번호로 배송 조회를 먼저 해 보고, 그래도 걱정되면 지원한 대학 입학처에 물어보세요.

## 올리기 전에 확인할 것

1. 모집요강에서 서류 이름, 받는 형식, 크기, 내는 방법을 확인해요.
2. 파일을 열어 모든 쪽이 있고 글자가 읽히는지 봐요.
3. 파일 이름에 특수문자나 띄어쓰기가 없는지 봐요.
4. 올린 뒤에는 원서접수 사이트에서 올린 파일을 다시 열어, 맞는 칸에 맞는 서류가 들어갔는지 확인해요.
5. 여러 대학에 지원한다면 대학마다 받는 서류와 형식이 다를 수 있어요. 한 대학에 맞춘 파일을 다른 대학에 그대로 올리지 말고, 대학마다 모집요강을 다시 확인해요.

고친 파일과 원래 파일은 한 폴더에 대학 이름별로 나눠 두면, 원서 접수가 끝난 뒤 서류를 다시 찾을 때도 편해요.
