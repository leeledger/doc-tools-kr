  • 사진 용량 줄이기

    곧 공개

  • 여권·증명사진 규격 맞추기

    곧 공개

  • 한글(HWP) → PDF 변환

    한글 프로그램 없이 HWP·HWPX 문서를 열어 보고 PDF로 저장하세요.

파일이 기기 밖으로 나가지 않습니다

일반적인 온라인 변환 사이트는 파일을 서버에 올린 뒤 처리합니다. 안올림은 처리 코드를 브라우저로 내려받아 내 기기에서 직접 실행합니다. 주민등록번호가 담긴 서류, 계약서, 증명사진도 외부 서버를 거치지 않습니다.

  • 업로드 없음파일 내용은 네트워크로 전송되지 않습니다.
  • 저장 없음창을 닫으면 작업한 파일은 기기 메모리에서 사라집니다.
  • 설치·가입 없음PC와 휴대폰 브라우저에서 바로 사용합니다.

자주 묻는 질문

정말 파일이 서버로 가지 않나요?

네. 변환과 압축은 모두 브라우저 안에서 실행됩니다. 브라우저 개발자 도구의 네트워크 탭에서 파일이 전송되지 않는 것을 직접 확인할 수 있습니다.

무료인가요?

기본 기능은 무료입니다. 운영비는 광고로 충당할 예정입니다.

여권사진 배경을 바꾸거나 보정해 주나요?

아니요. 여권 사진은 배경 합성이나 보정이 허용되지 않습니다. 안올림은 규격에 맞게 자르기, 크기 조정, 용량 조정만 합니다.

언제 사용할 수 있나요?

각 도구는 실제 공공 문서와 사진으로 품질 검증을 마치는 대로 차례로 공개합니다.
