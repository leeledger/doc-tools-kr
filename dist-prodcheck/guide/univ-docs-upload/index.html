대학 원서 서류 올리기, 용량·파일이 안 될 때

받는 서류와 형식·용량은 지원하는 대학의 모집요강에서 확인하고, 유웨이는 파일이 너무 크거나 확장자가 맞지 않거나 파일 이름에 특수문자가 있으면 안 올라간다고 안내해요.

PDF 서류 용량 줄이기

파일이 안 올라가는 세 가지 이유

유웨이 원서접수 안내에 따르면 서류 파일이 올라가지 않는 경우는 이 세 가지예요.

  1. 파일 크기가 너무 큰 경우
  2. 받는 확장자(파일 형식)가 아닌 경우
  3. 파일 이름에 특수문자 등이 들어간 경우

파일 이름에 특수문자나 띄어쓰기가 있으면 올리기 어렵다고 하니, 이름은 한글이나 영문으로만 바꿔 두세요. 받는 형식과 크기는 지원하는 대학의 모집요강에서 확인하세요.

파일이 너무 클 때

  • PDF 서류는 PDF 용량 줄이기에서 줄일 수 있어요.
  • 사진으로 찍은 서류는 사진 용량 줄이기에서 원하는 KB 이하로 줄일 수 있어요.
  • 여러 장을 하나의 PDF로 내야 하면 PDF 합치기로 묶을 수 있어요.

A4 크기로 올려 달라고 할 때

스캔하거나 사진으로 찍은 PDF는 A4 용지를 찍었어도 대학이 원하는 크기와 다를 수 있어요. 유웨이는 이렇게 다시 저장하라고 안내해요.

  1. 고칠 PDF 파일을 열어요.
  2. 인쇄 버튼을 눌러요.
  3. 프린터를 PDF로 골라요.
  4. 용지를 A4로 정해요.
  5. 인쇄를 눌러 PDF로 다시 저장해요.

원서는 윈도우 PC에서

유웨이 안내에 따르면 파일 제출과 원서접수는 윈도우 PC의 크롬·엣지에 맞춰져 있고, 맥과 휴대폰에서는 되지 않아요. 휴대폰으로 찍은 서류는 PC로 옮겨 제출하세요.

자주 묻는 질문

서류 파일이 원서접수 사이트에 안 올라가요.

유웨이 안내에 따르면 파일이 너무 크거나, 받는 확장자(파일 형식)가 아니거나, 파일 이름에 특수문자가 있으면 안 올라가요. 파일을 오른쪽 클릭해 [속성]에서 형식과 크기를 확인하세요.

A4 크기로 올려 달라는 창이 떠요.

유웨이는 PDF를 열어 인쇄 버튼을 누르고, 프린터를 PDF로, 용지를 A4로 골라 PDF로 다시 저장하라고 안내해요.

맥이나 휴대폰으로도 서류를 낼 수 있나요?

유웨이 안내는 맥과 휴대폰에서는 파일 제출과 원서접수가 되지 않고, 윈도우 PC의 크롬·엣지에 맞춰져 있다고 해요.

어떤 서류를 내야 하나요?

지원하는 대학의 모집요강에서 확인해요. 유웨이는 서류 제출 방법이 대학에 따라 다르다고 안내하고, 진학사는 제출서류 상담을 하지 않으니 대학 모집요강이나 입학처에 확인하라고 해요.

압축 파일(ZIP)로 내라고 해요.

유웨이 안내에 따르면 압축 파일이 필요한 경우가 있어요. 윈도우에서는 파일을 고른 뒤 오른쪽 클릭 > 보내기 > 압축(ZIP) 폴더로 만들 수 있어요.
