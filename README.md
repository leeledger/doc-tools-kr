# 안올림 (doc-tools-kr)

파일을 올리지 않는 서류 도구: PDF 합치기, PDF 용량 줄이기, 사진 용량 줄이기, HWP PDF 변환. 모든 처리는 브라우저 안에서 합니다.

- 개발: `npm ci`, `npm run dev`; 빌드: `npm run build`; 검사: `npm run check`, `npm test`, `npm run test:e2e`.
- 인수인계 문서: `handoff/`, 문구 가이드: `docs/COPY.md`, HWP 엔진: `docs/HWP-ENGINE.md`.

본 제품은 한컴의 HWP 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다.

한글, 한컴, HWP, HWPX는 한글과컴퓨터의 등록상표이며, 본 서비스는 한글과컴퓨터와 무관합니다.
