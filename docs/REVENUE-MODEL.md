# 문서딱 수익 모델 · 운영 자동화 플랜 (2026-10-12)

이 판은 검증 보고서 `reports/문서딱 수익화 전략 검증.md`(2026-10-12)의 결론을 따른다. 아래 숫자와 정책 내용의 출처는 모두 그 보고서다.

## 0. 원칙
- 도구는 영구 무료다.
- 수익은 트래픽과 결과물(인화·출력)에서 나온다.
- 파일은 어떤 경우에도 기기 밖으로 나가지 않는다(배경 지우기 서버 처리는 CLAUDE.md의 예외 그대로).
- 외부 스크립트가 필요한 수익원은 안내 글 경로(/guide/)에만 둔다. 도구·결과·404 화면에는 넣지 않는다.
- 운영은 사람 손 없이 돌아가야 한다. 사람이 꼭 해야 하는 일은 §8에만 적는다.

## 2. 숫자
**실측 (2026-10-10, 4일):** 10/7~10/10 방문 267, 페이지뷰 372. 미국 146은 대부분 배포 후 자동 점검으로 보이며(2026-10-10부터 통계에서 제외), 실제 한국 방문은 하루 25~35회 → 월 약 1,000방문·1,400 PV. 유입: 직접 190, 네이버 블로그 51, 네이버 검색 22, 구글 4.

**필요량:** 월 10만 원에는 월 3만~6만 PV가 필요하다(RPM 추정치 기준). 광고를 안내 글에만 넣으면 수익이 나는 PV는 전체의 일부뿐이라, 필요한 전체 PV는 3만~6만보다 커진다.

**시나리오 (월 1,400 PV 출발, 같은 성장률이 이어진다고 단순 계산):**
| 월 성장률 | 구분 | 하루 방문 100회(R1 조건) | 월 2.5만 PV | 월 5만 PV |
|---|---|---|---|---|
| 25% | **기본** | 2027년 3월 | 2027년 11월 | 2028년 2월 |
| 40% | 낙관 | 2027년 1~2월 | 2027년 6~7월 | 2027년 8~9월 |
| 15% | 보수 | 2027년 6월 | 2028년 6~7월 | 2028년 11월 |

- 월 10만 원은 기본 시나리오에서 2027년 11월~2028년 초다.
- 2027년 상반기에 광고를 켜도 기대치는 월 수천~1만 원대다.
- **계절:** 증명사진 검색은 2월 말~3월 초와 10월, 여권사진은 8월 말과 12~1월에 정점을 찍는다. 10월 데이터로 잰 성장률은 부풀려질 수 있고, 11월 말~12월 초에는 꺾여 보일 수 있다.

## 3. 정책 메모
**애드센스**
- 광고를 넣지 않는 화면: 도구 화면(업로드 버튼만 있는 화면), 결과 화면, 404. 구글 게시자 정책이 내용 없는 화면과 행동 목적 화면에 광고를 허용하지 않는다. 광고는 안내 글(/guide/)에만 둔다.
- CSP: 애드센스는 nonce 기반 strict CSP만 지원한다. 정적 배포라 요청마다 nonce를 만들 수 없으므로 해시 기반 strict CSP 또는 Pages Functions(무료 한도를 먼저 확인)로 간다. 광고용 CSP는 `_headers` 경로별 규칙으로 /guide/*에만 건다.
- 자동 점검: A-4 "외부 스크립트 0개"와 라이브 스모크 "외부 요청 0"의 검사 범위를 /guide/에 맞게 조정해야 한다.
- 개인정보: 개인정보처리방침 v2(Google 광고 쿠키, 거부 방법, 보관 기간), 첫 방문 고지, 14세 미만 맞춤광고 끄기.
- A-7 콘텐츠 루프로 기관 이름만 바꾼 글을 대량으로 만들면 구글 스팸 정책에 걸려 승인과 순위를 함께 잃을 수 있다.

**제휴 링크**
- 공정위 「추천·보증 심사지침」(2024-12-01 시행): 경제적 이해관계를 첫 부분, 링크 앞에 표시한다. 문서딱은 링크 묶음 맨 앞에 고지 문단을 두고, 링크 이름마다 「광고」를 넣는다.
- 쿠팡 파트너스: 떠다니는 배너 금지(2025-01부터), 지정 고지 문구 사용. 문서딱은 텍스트 링크만 쓴다(배너·이미지·스크립트 없음).

**세금**
- 애드센스 수익은 사업소득으로 5월 종합소득세 신고 대상이다.
- 쿠팡 파트너스는 3.3% 원천징수, 최소 지급액 2만 원.

## 4. 재평가
기존의 "2026-11-10에 하루 실제 방문 100회 미만이면 재검토" 규칙은 지운다. 월 40% 시나리오에서도 11월에 하루 100회는 어려워 판단 도구가 되지 못한다. 대신 아래 지표를 같은 날 함께 본다.

| 지표 | 계속(현재 전략 유지) | 조정(타임라인 늦춤) | 재검토(유입 전략 변경) | 데이터 출처 |
|---|---|---|---|---|
| 실제 방문 4주 월환산 성장률(자동 점검 제외) | 30% 이상 | 15~30% | 15% 미만 | 관리자 페이지·Cloudflare 통계 |
| 증명사진 군집 검색 노출·평균 순위(구글+네이버) | 노출 증가, 상위 5위권 진입 키워드 증가 | 노출 증가, 순위 정체 | 노출 정체·감소 | 서치콘솔 / 서치어드바이저 |
| 안내 글 클릭률(노출 대비) | 유지 | 하락하나 도구 페이지 유입이 보완 | 하락하고 도구 유입도 정체 → AI 요약 영향으로 판단 | 서치콘솔 / 서치어드바이저 |
| 유입원 분산(최대 단일 출처 비중) | 60% 미만 | 60~80% | 80% 이상 | 관리자 페이지·Cloudflare 통계 |
| "이어서 하기" 비율(도구 방문 대비) | 10% 이상 | 5~10% | 5% 미만 | 익명 사용 통계 |
| 브랜드 검색("문서딱") 노출 | 매달 증가 | 정체 | 감소 | 서치콘솔 / 서치어드바이저 |
| 인화·사진관 링크 누름(증명사진 저장 성공 대비) | 3% 이상 | 1~3% | 1% 미만 | 익명 사용 통계 |

- 날짜: **2026-11-10** 1차, **2026-12-15 전후** 2차. 2차는 10월 성수기 효과를 거르기 위한 것이다. 11-10 결과가 "계속"이어도 12월 확인 전에는 낙관하지 않는다.
- 기준치는 제안값이며 첫 측정 뒤 조정한다.
- "이어서 하기"는 버튼을 누른 횟수로 센다. 파일이 다음 도구에서 열렸는지는 세지 않는다(관리자 페이지 표의 안내 문구와 같다). 링크 누름도 누른 횟수일 뿐 주문 여부는 알 수 없다.
- **R3 검토 신호:** 링크 누름이 증명사진 저장 성공 대비 3% 이상으로 4주 이어지고 월 30회 이상이면 대표에게 R3 판단을 요청한다.
- 애드센스 승인 뒤에는 M-4로 실제 RPM을 재고 §2 시나리오를 다시 계산한다.
