- 안내 페이지와 `/og/`는 서비스 워커에 미리 저장하지 않습니다(450 KB 한도).

## 처음 한 번

1. **Google Search Console**: DNS TXT로 도메인 속성 등록 → `https://docttak.com/sitemap.xml` 제출 → pages.dev에서 주소 변경 신청.
2. **네이버 서치어드바이저**: `PUBLIC_NAVER_SITE_VERIFICATION`으로 소유 확인 → 사이트맵과 **RSS(`/guide/rss.xml`)** 제출 → 「웹 페이지 수집」으로 상위 10개 URL 요청.
3. **Bing Webmaster Tools**: Search Console에서 가져오기.
4. **IndexNow**: 배포 뒤 `npm run ping:indexnow -- --sitemap` 한 번.

## 배포할 때마다

1. 배포가 끝나면 키 파일이 열리는지 확인: `https://docttak.com/87c53aad239a45ff5caa9ce574b5e423.txt`.
2. 바뀐 URL만 IndexNow로 알립니다: `npm run ping:indexnow -- https://docttak.com/guide/passport-photo/ …`
   - `--dry-run`: 보낼 내용만 출력.
   - 키 파일이 사이트에 없으면 아무것도 보내지 않고 멈춥니다(exit 1). 다시 시도하지 않으니, 원인을 고친 뒤 다시 실행하세요.
3. 카카오톡 미리보기가 옛 이미지면 카카오 공유 디버거에서 캐시를 지웁니다.

## 매주 (5분)

- **Search Console**: 노출 상위 20개 검색어. 평균 순위 8–20위인 검색어는 해당 안내의 `title`과 `answer`만 고치고, `updated`를 올려 배포한 뒤 IndexNow로 알립니다.
- **서치어드바이저**: 수집 오류.
- **Bing**: AI Performance의 인용 수.

## 매달 (15분)

스프레드시트에 한 줄: 색인된 페이지 수(Google, 네이버, Bing), 클릭 수, 새 검색어, Bing AI 인용 수. 아직 재지 않은 검색어(공무원 시험 사진 규격, 큐넷 사진 등록, 이력서 사진 규격, 첨부파일 용량 제한, 운전면허 사진 규격 2026 등)를 네이버 키워드 도구로 재서 기록합니다. 제목을 처음 고치기 전에 먼저 잽니다.

## 안내 페이지 추가·수정 규칙

- 파일: `src/content/guides/<slug>.md`. 규격 숫자는 **직접 가져온 공식 안내의 인용문**(`sources[].quote`, 300자 이하, 확인일 포함), 여권·증명사진 프리셋(`{ preset: id }`), 도구 사실(`toolFacts`, `src/data/tool-facts.ts`)에서만 옵니다. 출처 없는 숫자+단위는 빌드가 실패합니다.
- 블로그, 뉴스, 경쟁 사이트는 출처가 아닙니다. 인용을 못 하면 `draft: true`로 두고 `blockedBy`와 `tried`(시도한 URL, 실패 내용)를 적습니다.
- 인용문은 화면에 나오지 않습니다(감사 기록). 본문은 풀어 쓰고 원문에 링크합니다.
- 쉬운 말: 업로드·서버·브라우저·네트워크·메모리·EXIF·px·dpi를 쓰지 않습니다(테스트가 막음).
