# 문서딱 — 사이티드 GEO 의뢰 브리프 (2026-10-01)

문서딱(https://docttak.com)은 사이티드의 두 번째 레퍼런스 후보다. 첫 번째 레퍼런스는 학원이고, 문서딱은 학원과 다른 업종인 무료 웹 도구다. 숫자는 측정한 것만 쓴다.

## 사이트 사실
- **도구 5개.** 모두 무료이고 가입이 없다. 파일은 기기 밖으로 나가지 않는다.
  - PDF 합치기 `/pdf-merge/`
  - PDF 용량 줄이기 `/pdf-compress/`
  - 사진 용량 줄이기 `/photo-compress/`
  - 여권·증명사진 규격 맞추기 `/id-photo/`
  - HWP PDF 변환 `/hwp-to-pdf/`
- **기술 구성.** Astro 정적 사이트를 Cloudflare Pages에 올렸다. 서버 처리, 쿠키, 분석 도구는 없다.
- **이미 되어 있는 것:**
  - robots.txt가 AI 검색 봇을 허용한다.
  - 페이지마다 JSON-LD(WebApplication, BreadcrumbList, FAQ)가 있다.
  - 페이지마다 OG 이미지가 있고, 사이트맵이 있다.
  - Google Search Console(도메인 속성)에서 소유 확인을 마쳤고 사이트맵을 제출했다.
  - 네이버 서치어드바이저에서 소유 확인을 마쳤고 사이트맵을 제출했다. 홈과 도구 5개는 수집 요청까지 했다.
  - 카카오 공유 캐시를 초기화했다.
- **진행 중 (`growth-g` 브랜치):**
  - `/guide/*` 안내 페이지. 첫 문장에 답을 쓰고, 공식 출처와 확인일을 단다.
  - 규격 딥링크 (`?preset=`, `?target=`)
  - RSS, IndexNow
  - 출처를 확보하지 못한 안내 페이지는 초안으로 남긴다.

## 측정 요청 (기준선 → 4주 → 8주)
질문 패널을 엔진별(ChatGPT, Gemini, Perplexity, Claude, 네이버 AI 브리핑)로 반복 측정한다. 결과는 "7일 n번 중 k번" 형식으로 기록한다. 질문은 실제 자동완성에서 가져왔다. 예시:
- pdf 합치기 무료 / 아이폰 pdf 합치기 / pdf 합치기 방법
- pdf 용량 줄이기 / 정부24 pdf 용량
- 사진 용량 줄이기 / 사진 kb 줄이기 / 증명사진 용량 줄이기
- 여권사진 규격 / 증명사진 사이즈 / 공무원 시험 사진 규격 / 큐넷 사진 규격
- 한글파일 pdf로 변환 / hwp pdf 변환 / hwpx 열기
- 안전한 pdf 합치기 / 파일 안 올리는 pdf 합치기

같은 질문에서 경쟁 도구(iLovePDF, Smallpdf, 알PDF, allinpdf, 한컴독스 등)가 몇 번 나오는지도 기록한다.

## 사이티드가 하면 좋은 것 (사이트 코드 밖)
- **외부 언급:** 네이버 블로그·카페·지식iN, 디스콰이엇·긱뉴스에 정당한 소개와 사용 후기를 확보한다. 대가성 글이면 표시한다.
- **위키류·비교 글:** "무료 PDF 도구 비교" 같은 글에 정확한 사실만 넣는다.
- **기록:** 측정 원문과 날짜를 보관하고, 사례 리포트로 정리한다.

## 하지 말 것
- 노출 보장 문구, 숨김 텍스트, 프롬프트 주입, 대량 생성 페이지, 가짜 후기를 쓰지 않는다. 구글이 2026-05-15에 스팸으로 명시했다.
- 사이트에 추적 스크립트나 제3자 스크립트를 넣지 않는다. CSP가 막고, 사이트의 약속("어디로도 보내지 않아요")과도 어긋난다.
- 사이트 코드 변경은 문서딱 저장소의 절차를 따른다. 설계 → 개발 → 리뷰를 거치고 배포한다.
