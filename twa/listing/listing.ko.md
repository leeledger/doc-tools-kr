기준: 2026-10-12 운영 사이트 (도구 15개, 배경 지우기 서버 모드 켜짐, 광고·제휴 링크 없음).
도구를 더하거나 빼면 이 파일의 목록도 고친다. 글자 수는 `README.md`의 확인 명령으로 잰다.

## 앱 이름 (30자 이내)

```
문서딱 - 증명사진·PDF 합치기·HWP 변환
```

## 간단한 설명 (80자 이내)

```
증명사진 규격 맞추기, PDF 합치기·압축, HWP를 PDF로. 파일은 폰 안에서 처리해요.
```

## 자세한 설명 (4000자 이내)

```
여권사진 규격, 원서에 올릴 사진 용량, 여러 PDF를 한 파일로, 한글(HWP) 파일을 PDF로.
내야 하는 문서·사진을 용량과 규격에 딱 맞춰 드려요. 가입도 광고도 없어요.

■ 파일은 폰 안에서 처리해요
PDF 합치기·압축, 사진 용량 줄이기, HWP 변환 같은 작업은 폰 안에서 바로 처리돼요.
고른 파일을 서버로 올리지 않아요. 단 하나의 예외는 「사진 배경 지우기」예요. 「사진을 보내지 않고 기기에서 처리」를
고르지 않으면, 배경을 지우려고 그 사진을 줄인 사본 1장을 암호화된 통신으로 보내고 결과를 돌려준 즉시 지워요.
「사진을 보내지 않고 기기에서 처리」를 고르면 사진을 보내지 않아요.

■ 쓸 수 있는 도구 (15가지)
· 여권·증명사진 규격 맞추기: 여권(413×531픽셀, 500KB 이하), 신분증, 운전면허, 시험·자격증 원서, 이력서 규격에 맞춰 자르고 용량을 맞춰요. 보정은 하지 않아요.
· 사진 용량 줄이기: 100KB·200KB·500KB처럼 원하는 용량에 맞추고, 촬영 위치 같은 사진 정보는 지워요.
· 사진 JPG 변환: 아이폰 사진(HEIC)·PNG·WebP를 JPG로 바꿔요. 여러 장을 한 번에 바꿀 수 있어요.
· 사진 PDF 변환: 사진 여러 장을 원하는 순서로 PDF 한 파일로 묶어요. A4 용지에 맞출 수도 있어요.
· 사진 배경 지우기 (누끼): 사진 배경을 지워 투명한 PNG나 흰 배경 사진으로 저장해요.
· PDF 합치기: 여러 PDF를 원하는 순서로 한 파일로 묶어요. 책갈피·링크도 그대로예요.
· PDF 용량 줄이기: 제출 용량 제한에 맞게 PDF를 줄여요. 글자는 선택·검색할 수 있는 그대로예요.
· PDF 나누기·쪽 편집: PDF를 여러 파일로 나누고, 필요 없는 쪽은 빼고, 쪽을 돌리거나 순서를 바꿔요.
· PDF JPG 변환: PDF의 쪽마다 JPG 사진으로 저장해요. 여러 쪽은 ZIP 파일 하나로 받아요.
· PDF 암호 해제·설정: 비밀번호를 아는 PDF의 암호를 풀고, 내 PDF에는 암호를 걸어요.
· PDF 서명·도장 넣기: PDF의 원하는 쪽, 원하는 자리에 서명이나 도장 그림을 넣어요.
· 전자서명·도장 이미지 만들기: 도장·서명 사진의 배경을 지워 투명한 PNG로 저장해요. 서명은 직접 그려도 돼요.
· HWP PDF 변환: 한글 프로그램 없이 HWP·HWPX 문서를 PDF로 바꿔요.
· HWP·HWPX 파일 보기: 한글 프로그램 없이 HWP·HWPX 문서를 열어 쪽을 넘겨 보고, 글자를 찾아 봐요.
· HWPX HWP 변환: HWPX 문서를 HWP로 바꿔요.

■ 이렇게 써요
1. 도구를 고르고 폰의 「파일」 앱이나 갤러리에서 파일을 골라요.
2. 규격이나 목표 용량을 고르면 바로 처리돼요.
3. 결과 파일은 폰의 다운로드 폴더에 저장돼요.

■ 편하게 쓰는 방법
· 앱 아이콘을 길게 누르면 증명사진, PDF 합치기, HWP 변환, 사진 용량 줄이기로 바로 갈 수 있어요.
· 결과 파일을 다른 도구로 바로 넘겨 이어서 작업할 수 있어요. 예: 사진 PDF 변환 → PDF 용량 줄이기.
· 앱을 처음 열 때와 도구를 처음 쓸 때는 인터넷이 필요해요. 한 번 연 뒤에는 인터넷이 끊겨도 대부분의 도구를 다시 쓸 수 있어요.
```
