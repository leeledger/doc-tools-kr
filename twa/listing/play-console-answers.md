# Play Console 답변 (앱 콘텐츠·데이터 보안)

이 답은 아래 **기준 상태**에서 코드와 운영 사이트를 확인해 만든 것이다. 기준 상태가 바뀌면 (광고·제휴 링크, 새 수집,
새 외부 서비스) 배포 **전에** 이 파일과 Play Console 답을 같이 고친다 (TWA brief F8, E4).

## 데이터 보안 (Data safety)

### 개요 질문
| 질문 | 답 | 근거 |
|---|---|---|
| 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **예** | 아래 표 |
| 전송 중 데이터가 모두 암호화되나요? | **예** | HTTPS 전용 사이트 (HSTS, `scripts/gen-headers.mjs`) |
| 사용자가 데이터 삭제를 요청할 수 있는 방법을 제공하나요? | **아니요** (권장, 아래 참고) | 계정 없음. 통계는 익명·합계, 배경 지우기 사진은 처리 직후 삭제. GA 쿠키는 앱 저장공간 삭제나 방침의 거부 방법으로 지울 수 있음 |
| 계정 생성 | **앱에서 계정을 만들 수 없음** | |

공유(Sharing): **없음.** Cloudflare·Google은 문서딱을 대신해 처리하는 서비스 제공업체이므로 Play 정의상 「공유」가 아니다
(방침 #bg 처리 위탁, #ga 광고 개인화·Google 신호 꺼짐).

### 수집하는 데이터 유형
| Play 데이터 유형 | 수집 | 필수/선택 | 임시 처리 | 목적 | 출처 (코드·방침) |
|---|---|---|---|---|---|
| 사진 및 동영상 > **사진** | 예 | **선택** (「사진을 보내지 않고 기기에서 처리」를 고르면 보내지 않음) | **예** (결과를 돌려준 즉시 삭제) | **앱 기능** | 방침 #bg, `src/lib/bgremove/mode.ts`, `functions/api/remove-bg.ts` |
| 앱 활동 > **앱 상호작용** | 예 | 필수 | 아니요 | **분석** | GA4 page_view (방침 #ga), Cloudflare Web Analytics (#analytics), 익명 사용 통계 이벤트 pick·start·success·download·next·out (`scripts/lib/usage.mjs`, #usage) |
| 앱 정보 및 성능 > **진단** | 예 | 필수 | 아니요 | **분석** | 사용 통계 `fail` 이벤트: 오류 종류·단계·브라우저 종류와 버전 (`scripts/lib/usage.mjs`) |
| 기기 또는 기타 ID > **기기 또는 기타 ID** | 예 | 필수 | 아니요 | **분석** | GA4 `_ga` 쿠키의 임의 번호, 최대 13개월 (방침 #ga) |
| 위치 > **대략적인 위치** | 예 | 필수 | 아니요 | **분석** | GA4가 IP로 지역 추정(IP 저장 안 함), Cloudflare Web Analytics 나라 (방침 #ga, #analytics). Arch 결정: 신고함 (과대 신고는 안전, 과소 신고는 위반) |

수집하지 않음: 이름·이메일·전화번호 등 개인 정보, 연락처, 정확한 위치, 금융 정보, 메시지, 건강 정보, 파일·문서
(고른 PDF·HWP·사진은 폰 안에서만 처리. 위 배경 지우기 사진 1장이 유일한 예외), 웹 기록, 설치된 앱, 오디오, 캘린더.

### 확인 필요 (Arch에게)
- **앱 상호작용**: brief 초안은 "앱 상호작용 = 아니요, 페이지 조회·상호작용 = 예"로 적었으나, Play 양식에는 「페이지 조회」라는
  별도 항목이 없고 페이지 방문·탭 수는 「앱 활동 > 앱 상호작용」의 정의에 들어간다. 이 파일은 **앱 상호작용 = 예**로 적었다.
  「기타 사용자 생성 콘텐츠」는 아니요 (사용자가 만든 내용을 받지 않음).
- **삭제 요청**: 계정이 없어 사람별로 찾아 지울 데이터가 없으므로 「아니요」를 권장. 「예」로 답하려면 요청 창구(이메일)와
  처리 절차가 방침에 있어야 한다.

## 최소 기능 정책으로 거절됐을 때 이의 제기 문안

```
문서딱은 웹사이트를 감싼 앱이 아니라, 폰 안에서 돌아가는 문서·사진 처리 도구 모음입니다.
- PDF 합치기·압축·나누기·암호, HWP→PDF 변환과 HWP 보기, 사진 용량 맞추기·여권사진 규격 맞추기를 기기 안의 엔진(WebAssembly)으로 처리하며, 파일을 서버로 올리지 않습니다.
- 15가지 도구, 홈 화면 바로가기 4개, 결과 파일을 다음 도구로 넘기는 이어서 하기 기능을 제공합니다.
- 한 번 연 뒤에는 인터넷 연결 없이도 대부분의 도구를 쓸 수 있습니다.
- 가입·로그인·광고가 없습니다.
```
